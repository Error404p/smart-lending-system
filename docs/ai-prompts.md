# AI Prompts History

This document records the incremental prompts and instructions executed across the 6-day build cycle.

---

1. **Scaffold (Day 1)**: "Initialize a fresh empty git repo, delete the old .git history. Setup package.json in root, backend and frontend folder placeholders, and add stub files under docs/."
2. **Schemas (Day 1)**: "Write User schema (member vs librarian role), Item schema (available vs borrowed), Loan, and LoanHistory schemas using Mongoose."
3. **Auth middleware & routes (Day 1)**: "Build register and login routes. Register should hash password with bcryptjs and issue token. Middleware needs to verify JWT and restrict access based on roles."
4. **Loan lifecycle & guards (Day 2)**: "Implement requested, issued, returned, and lost loan lifecycle transitions. Add a MongoDB partial unique index on active loans (Requested/Issued) per item as a concurrency checkout guard. Setup automated testing with MongoMemoryServer."
5. **Audit, Custodians & Overdue Alerts (Day 3)**: "Audit registration endpoint to prevent client-supplied role assignment. Add many-to-many librarians to catalogue items custodianship. Create append-only history timeline entries for every transition with authors and notes. Build overdue alert lists with scoped loan-level dismissals. Boot a React client in the frontend using Vite and plain CSS styles."
6. **Server-Side Search, Filtering, Sorting & Pagination (Day 4)**: "Implement server-side search over item title and borrower, filter by status, item, and borrower, sort by due date, requested date, and status, and paginate with total match counts and total pages. Enforce role permissions strictly on the server by pinning member queries to their own user ID. Wire up the React frontend list view with plain CSS filter controls and pagination buttons."
7. **Bulk Actions & Operations Dashboard (Day 5)**: "Implement CSV bulk import for catalogue items with per-row failure reports. Implement bulk return of issued loans with per-loan status and rejection reasons. Implement CSV export of active checkouts. Implement operations dashboard with headline numbers (items out, overdue, returned this week, total catalogue items), breakdown by status and librarian custodian, and an 8-week return trends bar chart using Chart.js. Strict server-side role enforcement on all endpoints."
   - *Note on test fix*: During initial test setup for Day 5, test user passwords were saved in raw text rather than bcrypt hashes in the mock DB setup script, which led to a 401 error upon login in the test harness. Corrected by running test seed passwords through `bcrypt.hash()` during test setup.
8. **Demo Seeding, Deployment Blueprints, Documentation & Final Audit (Day 6)**: "Extend seed data with 3 librarians, 5 members, 17 items, 26 loans across all lifecycle states including Lost and 8 weekly return buckets for chart visualization. Prepare Render blueprint (render.yaml), Vercel SPA routing (vercel.json), and environment templates (.env.example). Write complete SUBMISSION.md, comprehensive docs/architecture.md with sequence and state diagrams, and run automated role-enforcement security audit suite confirming 19/19 checks pass."
